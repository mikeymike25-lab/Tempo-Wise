# Tempus Wise

**Make Time Work for You.**

Tempus Wise is a time-management and productivity app for students and workers,
combining schedule planning, focused work sessions, routines, reminders, and
progress tracking into one place.

## The Problem
Students and workers struggle with poor time management, disorganized schedules,
procrastination, inconsistent habits, forgotten deadlines, and poor work-life balance.

## The Solution
Five core tools in one app:
- 📅 Smart Schedule Maker
- 🍅 Focus Timer (25/5, 25/10, 50/10, 90/20, custom)
- 🔄 Routine Maker
- 🔔 Reminders
- 📊 Progress Tracking
