# Project: Tempus Wise

## Tagline
"Make Time Work for You."

## Problem
- Poor time management
- Disorganized schedules
- Procrastination
- Difficulty balancing responsibilities
- Forgetting tasks and deadlines
- Poor work-life balance
- Can't see whether they're actually improving

## Target Users
Students and working professionals juggling school/work/personal responsibilities
who want one place to plan, focus, and track progress.

## Problem → Solution

| Problem | Tempus Wise Feature |
|---|---|
| Poor time management | 📅 Smart Schedule Maker |
| Disorganized schedules | 📅 Schedule Maker |
| Procrastination | 🍅 Focus Timer (Pomodoro) |
| Lack of consistency | 🔄 Routine Maker |
| Forgetting tasks | 🔔 Reminders |
| Can't see improvement | 📊 Progress Tracking |
| Poor work-life balance | 📅 Schedule + 🔄 Routine |

## Core Features
1. **Smart Schedule Maker** – add tasks/events with date, time, priority, notes.
2. **Focus Timer** – Pomodoro-style sessions: 25/5, 25/10, 50/10, 90/20, custom.
3. **Routine Maker** – repeatable checklists (Morning Routine, Study Routine) for consistent habits.
4. **Reminders** – notify users of upcoming tasks, sessions, and routines.
5. **Progress Tracking** – tasks completed, focus time, streaks, productivity breakdown.

## Value Flow
Splash → Login/Sign Up → Home Dashboard → Smart Schedule → Add Task → Focus Timer → Routine Maker → Reminders → Progress Tracking → Profile/Settings
